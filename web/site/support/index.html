Assistance — CASPROD

Une question, un problème avec l’application, ou une demande concernant vos données ? Écrivez-nous à contact@casprod.app. Nous répondons en général sous deux jours ouvrés.

Vous êtes employé

  • Je ne peux pas me connecter. Votre identifiant et votre mot de passe sont créés par votre chef ; il peut réinitialiser le mot de passe depuis votre fiche. Si vous avez rejoint avec un code d’affiliation, utilisez l’identifiant choisi à l’inscription (pas une adresse e-mail).
  • Je ne reçois pas les vérifications de présence. Vérifiez que les notifications sont autorisées pour CASPROD dans les réglages du téléphone, et qu’une journée est bien en cours dans l’application.
  • Je veux arrêter le partage de position. Depuis l’écran de votre journée, retirez votre accord : le partage s’arrête immédiatement.
  • Je veux accéder à mes données ou les faire corriger. Adressez-vous à votre chef, responsable de l’usage de l’application dans votre entreprise, ou écrivez-nous.

Vous êtes chef

  • Ajouter un employé. Onglet Employés → ajouter, ou partagez le code d’affiliation de l’entreprise.
  • Un employé a oublié son mot de passe. Ouvrez sa fiche → réinitialiser le mot de passe.
  • La carte est vide sur Android. Mettez l’application à jour depuis le Play Store ; si le problème persiste, écrivez-nous en précisant le modèle du téléphone.

Supprimer son compte

Dans l’application : Compte → Supprimer mon compte. Les effets sont décrits dans la politique de confidentialité. Si vous n’avez plus accès à l’application, envoyez la demande depuis l’adresse e-mail (chef) ou en indiquant votre identifiant et le nom de votre entreprise (employé) à contact@casprod.app ; nous confirmerons la suppression par retour.
